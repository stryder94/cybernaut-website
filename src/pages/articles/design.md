# The Cybernaut Manifest

> "A computer system that came online in 1989 and never went offline."

Cybernaut is more than a personal website.

It is a fictional operating system that has quietly evolved through every era of computing while keeping its original personality.

Visitors shouldn't feel like they're browsing another portfolio.

They should feel like they've connected to a legendary machine that has been continuously running for decades.

---

# Guiding Principles

Technology should feel approachable.

The interface should reward curiosity.

The design should inspire exploration.

Every page should tell a story.

---

# Design Inspiration

Cybernaut draws inspiration from four eras of computing.

## 🕹️ Late 80's Arcades

The personality.

Bright colors.

Marquee lighting.

Pixel artwork.

Neon glow.

Bold geometric interfaces.

Examples include:

- OutRun
- Space Harrier
- After Burner
- Sega arcade cabinets

---

## 💾 Bulletin Board Systems (BBS)

The navigation.

Simple.

Functional.

Dense.

Information comes first.

The interface should encourage exploration instead of distraction.

---

## 💻 DOS and Early Personal Computing

The operating system.

Projects become software modules.

Articles become system logs.

The About page becomes a user profile.

The Now page becomes a system status display.

Cybernaut should feel like software instead of a collection of webpages.

---

## 🌆 Cyberpunk & Synthwave

The atmosphere.

These elements should support the experience instead of dominating it.

Neon lighting.

Purple skies.

Deep space.

Retro futurism.

CRT glow.

Grid horizons.

The atmosphere surrounds the interface.

It should never overpower readability.

---

# Color Philosophy

Primary (Cyan)

Technology.

Navigation.

HUD elements.

Interactive links.

---

Secondary (Purple)

Borders.

Panels.

Ambient glow.

Depth.

---

Accent (Pink)

Hover effects.

Buttons.

Active selections.

Neon highlights.

Interaction should feel alive.

---

# Cybernaut Is

A computer.

An operating system.

An archive.

A laboratory.

A journal.

A place for experimentation.

A place to learn publicly.

---

# Cybernaut Is Not

A corporate website.

A SaaS landing page.

Minimalism for its own sake.

Glassmorphism.

Material Design.

Trend chasing.

Every visual decision should strengthen the illusion that Cybernaut has existed since 1989.

---

# The User Experience

The visitor is not browsing.

The visitor is exploring.

Projects are installed software.

Articles are system logs.

Documentation becomes manuals.

Status updates become system diagnostics.

Learning becomes mission logs.

---

# North Star

Whenever a design decision is uncertain, ask one question.

**Does this belong in Cybernaut OS?**

If the answer is yes, it belongs.

If the answer is no, it should be reconsidered.

Cybernaut should always feel like a legendary computer system that has quietly remained online since 1989 while continuously evolving with modern technology.

That feeling is more important than any individual color, font, animation, or visual effect.
